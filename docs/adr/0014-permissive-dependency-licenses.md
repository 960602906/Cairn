# ADR-0014 只使用宽松许可证的依赖

- 状态：已接受
- 日期：2026-11-02

## 背景

项目暂时私有，后续计划开源，开源时的许可证尚未确定（倾向 MIT 或 Apache-2.0）。如果私有期间引入了 GPL、AGPL 等强著佐权（copyleft）许可证的依赖，开源时可能被迫选择特定许可证或替换依赖。

## 决定

- 直接和间接依赖只允许 MIT、Apache-2.0、BSD、ISC 等宽松许可证。
- 在 CI 中加入许可证检查脚本，出现不在白名单内的许可证时构建失败。
- 随应用打包的外部二进制（如 ripgrep、Git）单独登记许可证，并在开源前确认分发合规。

## 备选方案

- **开源时再统一检查**：可能面临大量替换工作。

## 后果

- 选型时少数依赖可能因许可证被排除。
- 开源时只需选择项目自身的许可证并补充第三方声明。
