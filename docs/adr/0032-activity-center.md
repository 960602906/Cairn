# ADR-0032 活动中心与跨会话审批聚合

- 状态：提议（M4-00 起草；M4-06 定稿）
- 日期：2026-11-08
- 详细设计：[Agent 管理界面](../design/agent-management-ui.md) §9；[多 Agent 协作](../design/multi-agent.md)
- 相关决策：ADR-0005、ADR-0009、ADR-0010、ADR-0013、ADR-0020

## 背景

M4 会有多个会话与子运行同时进行，审批不再只属于当前打开的会话。用户需要一个地方看到所有待审批、运行中与最近完成的任务，并在应用不在前台时收到提醒。候选方案：

1. 渲染进程从各会话状态自行聚合；
2. 主进程聚合，渲染进程订阅；
3. 每个审批都直接弹系统通知。

方案 1 在窗口隐藏、会话未打开或宿主未挂载时看不到；方案 3 会产生通知风暴，也可能泄露消息正文。

## 决定

- **主进程聚合。** 审批索引与运行状态由主进程维护，来源是事件日志、审批服务与宿主状态；活动中心通过 `activity.list` / `activity.resolve` 读取与处理，变更通过 `activity.changed` 推送。
- **只读投影。** 活动中心不修改事件，也不维护第二份运行状态；会话内行为保持不变。
- **侧栏角标。** 待审批数量由同一个聚合结果驱动；角标与列表必须一致。
- **系统通知。** 只在所有窗口都不在前台（或不可见）且用户未关闭通知时发送；按会话合并，同一会话 15 秒内最多一条。
- **内容最小化。** 通知只包含 Agent 名称、会话标题与固定动作文案，不包含消息正文、工具参数、文件内容、路径或凭据。
- **点击路由。** 点击通知只携带 `sessionId`，由主进程聚焦窗口并让渲染进程打开对应会话；不携带 URL 或文件路径。
- **失败不阻塞。** 通知失败（系统不支持、勿扰模式、权限拒绝）只记录日志，不影响审批本身；侧栏角标仍是权威提示。
- **试运行排除。** `kind = 'trial'` 的会话不出现在活动中心、角标与用量统计中。
- **不引入新依赖。** 使用 Electron `Notification` 与现有主进程服务。

## 备选方案

- **渲染进程聚合**：窗口隐藏时失效，不采用。
- **每个审批直接通知**：通知风暴且容易泄露内容，不采用。
- **通知携带消息摘要**：方便但越过隐私边界，不采用。

## 后果

- 审批服务需要增加全局索引，并保证 `sessionId` / `runId` / `parentRunId` 的归属正确。
- 活动中心需要处理宿主崩溃：写入 `session.crashed`，移除该会话的运行中项，不误伤其他会话。
- 通知是增强能力；真实桌面上的勿扰模式与点击聚焦必须由用户本地验收。
