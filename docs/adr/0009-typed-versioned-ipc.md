# ADR-0009 类型化、带版本的进程间通信协议

- 状态：已接受
- 日期：2026-11-02

## 背景

应用包含渲染进程、主进程和多个 Agent 宿主进程。如果各处用字符串通道名和无校验的对象通信，接口一改就容易漏改，且错误只在运行时偶然暴露。

## 决定

- 所有进程间消息定义在 `packages/protocol` 中，使用 zod 定义 schema 并导出 TypeScript 类型。
- 两类消息：带 id 的请求/响应（支持超时）和单向事件流。
- 收发两端都进行运行时校验，校验失败记录日志并返回明确错误。
- 连接建立时交换协议版本，不兼容时拒绝连接。
- 预加载脚本只暴露由协议生成的类型化 API，不暴露通用的 `ipcRenderer`。
- 错误使用错误码加参数传递，由界面按当前语言翻译。

## 备选方案

- **直接使用 `ipcMain` / `ipcRenderer` 字符串通道**：简单，但缺乏约束。
- **tRPC 等现成方案**：可行，但会引入额外依赖，且需要适配 MessagePort；保留为实现层面的选择，不影响本决定。

## 后果

- 协议变更集中在一个包内，类型检查能发现大部分不一致。
- 运行时校验有少量性能开销；对高频的增量事件可只在开发模式下校验。
