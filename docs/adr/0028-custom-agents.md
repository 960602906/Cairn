# ADR-0028: 自定义 Agent 存储、版本与运行隔离

## 背景

M3-11 与 M3-12 引入了自定义 Agent 定义、编辑、版本历史与会话选用。Agent 定义包含提示词指令、模型配置、工具与 Skills 选择器、权限策略及单轮限额。需要确保：
1. 编辑中的草稿改动不能影响已在执行的会话。
2. 历史会话中的运行必须精准可重现。
3. 内置 Agent 与用户自定义 Agent 的生命周期有明确界限。

## 决策

1. **双层存储模型**：
   - `agents` 表维护 Agent 元信息（id、来源、归档状态）与当前活跃草稿定义（`draft`）。
   - 每次发布操作向 `agent_versions` 写入一份只读版本记录，版本号从 1 开始严格自增。
2. **运行绑定具体版本（不可变性）**：
   - 会话创建运行（`run.created`）时记录 `agent: { id, version }`。
   - 运行中根据 `(id, version)` 提取固定快照，不受后续草稿保存或新版本发布影响。
3. **删除与归档约束**：
   - 从未在任何会话运行中使用的 Agent 允许彻底删除。
   - 已产生历史运行记录的 Agent 仅允许“归档”，不可物理删除，以确保历史会话完整展示与审计。
   - 内置 Agent（`builtin.coder`）受保护，禁止修改、归档或删除，仅允许复制为自定义 Agent。
4. **运行时切换模式**：
   - 会话内切换 Agent 立即在同一会话下派生新运行（`RunView`），历史消息自动作为后续轮次上下文继承。

## 状态

已采纳并实施（M3-11、M3-12）。
