# ADR-0013 中英双语国际化

- 状态：已接受
- 日期：2026-11-02

## 背景

界面需要支持中文和英文，项目后续计划开源，面向更多用户。如果开发初期硬编码中文文案，后续补英文需要逐个排查组件和错误信息，成本很高。

## 决定

- 使用 i18next + react-i18next，资源放在 `packages/i18n/locales/{zh-CN,en-US}/`，按命名空间拆分。
- 组件中禁止硬编码文案，由 ESLint 规则检查。
- 主进程的菜单、对话框、通知、错误提示共用同一套资源。
- 进程间以错误码传递错误，由界面按当前语言翻译。
- 首次启动跟随系统语言（非中文默认英文），设置中可即时切换。
- CI 检查两种语言的 key 完全一致。
- 给模型的系统提示词和工具说明使用英文；模型回复语言跟随用户提问。

## 备选方案

- **先做中文，以后再加英文**：开发初期稍快，但后补成本高。
- **其他 i18n 库（如 FormatJS）**：功能相近；i18next 生态更大，也可用于主进程。

## 后果

- 每新增一条文案都需要同时提供中英文。
- 日志和协议中不出现特定语言的文本，便于排查问题和开源协作。
