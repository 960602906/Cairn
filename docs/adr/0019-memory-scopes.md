# ADR-0019 记忆范围（预留）

- 状态：已接受（功能暂缓）
- 日期：2026-11-02
- 详细设计：[Agent Runtime 详细设计第 22 节](../design/agent-runtime.md#22-记忆预留)

## 背景

Agent 跨会话记住项目约定、用户偏好会很有用，但如果把所有上下文混在一起，会导致信息泄露到不相关的项目、Agent 行为难以预测。第一版不打算实现记忆，但 Agent 定义和上下文组装需要为它留出位置。

## 决定

- 记忆分为三个范围：会话、项目、全局，严格隔离。
- Agent 定义增加 `memory` 字段，声明可读取的范围和写入方式（`never` / `propose` / `auto`）。
- 所有记忆条目对用户可见、可编辑、可删除，并记录来源。
- 第一版写入方式固定为 `never`，不实现读取；以后开放时默认 `propose`，需用户确认后写入。

## 备选方案

- **不做范围划分，统一记忆**：简单，但会跨项目泄露信息。
- **完全不预留**：以后需要修改 Agent 定义 schema 和上下文组装顺序。

## 后果

- Agent 定义多一个暂不生效的字段。
- 记忆功能可以在不修改数据结构的前提下增加。
