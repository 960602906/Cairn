# ADR-0015 使用 pnpm monorepo 并强制依赖边界

- 状态：已接受
- 日期：2026-11-02

## 背景

本项目的多项决策依赖清晰的模块边界：只有一个包能引用 pi（ADR-0004），协议独立定义（ADR-0009），权限引擎可独立测试（ADR-0007）。如果所有代码都在一个包里，这些边界只能靠约定，很快会被打破。

## 决定

- 使用 pnpm workspace 组织 monorepo：`apps/desktop` 加若干 `packages/*`（见架构文档第 5 节和第 25 节）。
- 依赖方向自上而下，`protocol` 和 `core` 位于最底层，不依赖上层包。
- 用 ESLint 依赖边界规则在 CI 中强制约束，例如只有 `runtime-pi` 可引用 pi。
- 共享 TypeScript 配置和 ESLint 配置。

## 备选方案

- **单包项目**：起步简单，但边界无法强制。
- **npm 或 yarn workspaces**：可行；pnpm 安装速度快、依赖隔离严格，能更早暴露未声明依赖的问题。

## 后果

- 初期需要多花一些时间搭建工作区和构建配置。
- 各包可独立测试，替换某个实现时影响范围明确。
