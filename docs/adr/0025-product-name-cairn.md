# ADR-0025 产品命名为 Cairn（石标）

- 状态：已接受
- 日期：2026-11-06

## 背景

项目一直使用工作名 NEXUS-OS。ADR-0023 之后的定位是“自研 Agent 平台 + 可插拔引擎”，原计划在 M5 发布前决定最终名称。M2 开始做正式界面和应用图标，名称需要提前定下来，否则图标、窗口标题、安装包和数据目录都要改两次。

候选与比较：

| 名称 | 含义 | 主要问题 |
|---|---|---|
| **Cairn（石标）** | 登山路上堆起的石头路标：每一段都有标记，随时能回头 | 英文词偏冷门，需要解释一次 |
| Keel（龙骨） | 船底的脊梁：引擎可以换，底座不变 | 与撤销、检查点这些核心体验关系不大 |
| Waypoint（航点） | Agent 每一步都留下一个点 | 词长，同名项目多 |
| Nexus（枢纽，保留现名） | 把模型、工具、MCP、技能连在一起 | 太常见（Sonatype Nexus、Google Nexus 等），搜索和商标都容易撞 |

## 决定

产品名定为 **Cairn**，中文名“石标”，标语“安心地让 Agent 动手”。

- 名称直接对应产品最重要的差异：每一轮自动保存检查点、任何一轮都能撤销；一块块石头叠起来，也对应多个 Agent 和工具的组合。
- 应用图标是三块叠起的石头，黑白灰配色（见[视觉规范](../design/visual-style.md)第 9 节）。
- 代码中的命名随之调整：
  - 界面上的产品名、窗口标题、安装包名称：`Cairn`；
  - 工作区包名前缀：`@nexus/*` 改为 `@cairn/*`；
  - 应用内部环境变量前缀：`NEXUS_` 改为 `CAIRN_`；
  - 应用 ID：`dev.cairn.desktop`。

## 备选方案

见背景中的比较表。保留 NEXUS-OS 改动最少，但名字辨识度低，“OS”也会让人误以为是操作系统。

## 后果

- GitHub 仓库名由 lan 在仓库设置中修改（GitHub 会自动把旧地址重定向到新地址）。
- 改名前在 GitHub、npm 和常用域名上确认没有冲突的同名产品；如有冲突，可加后缀（例如 Cairn Code），本 ADR 随之更新。
- 应用 ID 和名称变化后，Electron 的用户数据目录也会变化，开发阶段的本地数据（数据库、凭据）不会自动迁移；目前没有正式用户，开发者手动迁移或重新配置即可。
- 历史文档（ADR、计划、实施记录）中的 NEXUS-OS 保留原样，作为当时的记录。
