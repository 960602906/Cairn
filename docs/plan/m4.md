# Cairn 里程碑 4：多 Agent 协作、活动中心与长期记忆 (M4 计划草稿)

> 起始基准：M3 完成后主分支状态（包含 MCP 连接、自定义 Agent、计划模式、上下文压缩、诊断包）
> 目标：实现多 Agent 委派协同、全局活动中心、会话外长期记忆与 Agent 试运行环境。

## 1. 目标与范围

在 M3 交付的单 Agent 核心能力基础上，M4 重点突破复杂多任务协同与长时间跨度的工作记忆，提供：
1. **多 Agent 协同与委派**：主 Agent 可将子任务委派给专门的子 Agent 执行，形成清晰的运行树与进度追踪。
2. **活动中心**：聚合后台并发运行、待审批集中处理、最近完成任务的统一工作台。
3. **长期记忆系统**：支持跨会话的知识积累、偏好记忆与结构化记忆检索。
4. **Agent 试运行面板**：编辑器内并排轻量试运行，支持草稿即时验证。

## 3. 任务清单草案

### M4-01 运行树与多 Agent 委派协议

- **协议扩展**：`RunView` 增加 `subruns` 拓扑关系与 `delegation` 契约；新增 `run.delegate` 事件。
- **调度引擎**：`RunSupervisor` 支持并发派生子运行，子运行继承限额沙盒并受父运行生命周期管控。
- **界面**：聊天面板与会话侧栏提供运行树状卡片折叠与展开。

### M4-02 全局活动中心

- **侧栏导航**：点亮侧栏“活动”入口，红点展示待审批总数与运行中总数。
- **统一待审批流**：跨会话聚合需要用户批准的敏感工具调用，支持就地查看差异与一键允许/拒绝。
- **后台任务监控**：多项目长任务并行时提供全局耗时、Token 消耗与实时日志抽检。

### M4-03 Agent 试运行面板

- **并排交互**：在 Agent 编辑器右侧并排开启轻量沙盒会话，不占用用户会话历史。
- **实时热重载**：左侧修改指令或工具配置后，右侧提示“草稿已变更”，支持一键重启试运行验证。
- **安全沙盒**：试运行默认严格只读（禁止写入文件与执行外部网络），可手动提升为 Agent 自有权限。

### M4-04 跨会话长期记忆（Memory）

- **存储架构**：本地 SQLite 嵌入向量与 FTS5 全文联合存储，提供 `memories` 领域。
- **记忆生命周期**：会话结束后由辅助模型自动提取高价值知识（项目规范、偏好、习惯），打上时间与来源标签。
- **读取注入**：系统提示词在 Layer 2 动态注入与当前任务语义相关的 Top-K 记忆片段；提供记忆管理与单条删除界面。

### M4-05 验收与综合收尾

- **全流程集成测试**：多 Agent 委派 + 长期记忆唤醒 + 活动中心并发审批完整链路走通。
- **性能与基准测试**：长时间多任务下内存平稳，UI 渲染无卡顿。
