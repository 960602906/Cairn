## 1. 范围与目标

本文档覆盖与 Agent 相关的所有界面：

- **管理 Agent 定义**：查看、创建、编辑、版本、发布、试运行、导入导出、归档。
- **使用 Agent**：在会话中选择和切换 Agent。
- **观察运行**：查看某次运行在做什么、花了多少、为什么这样做。
- **管理 Agent 依赖的能力**：Skills 与 MCP 服务。

设计目标：

1. **会话是主场，管理是配角。** 产品是编程优先的，用户大部分时间在会话里写代码，管理界面不能抢占主要入口。
2. **看得懂为什么。** Agent 的行为由指令、模型、工具、Skills、权限、限额共同决定，界面要能回答"这个 Agent 为什么能做或不能做这件事"。
3. **改了不会出事。** 编辑不会影响正在运行或历史的会话（版本机制），发布前可以试运行。
4. **新手零配置可用。** 不碰管理界面，只用内置的"编程助手"也能完成全部基本工作。

```

├──────────────────────────────────────────────────────────────┤

│                                       最近使用 2 分钟前  ⋯    │
├──────────────────────────────────────────────────────────────┤
│ ◇ 代码探索               内置   跟随会话                       │
│   只读，适合理解项目、回答问题             工具 3 · 只读       │
├──────────────────────────────────────────────────────────────┤
│ ● 前端审查员  v3          自定义   DeepSeek                    │
│   按团队规范审查 React 代码               工具 3 · Skills 2   │
│   ⚠ 依赖的 MCP 服务 github 未连接                         ⋯    │
├──────────────────────────────────────────────────────────────┤
│ ○ 测试补全  草稿          自定义   Ollama · qwen               │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 每一行显示

- 图标与颜色、名称（当前界面语言）、来源（内置 / 自定义 / 导入）。
- 状态：已发布（显示版本号）、草稿、有未发布的修改。
- 模型：固定模型名，或"跟随会话"。
- 能力摘要：工具数量、Skills 数量、是否只读。
- 最近使用时间、累计运行次数。
- 警告：引用的工具、Skill 或 MCP 服务不可用；模型不支持工具调用。

### 3.3 操作

- **新建**：弹出选择——"从空白开始"或"基于已有 Agent 复制"。默认推荐基于"编程助手"复制，避免用户从零写指令。
- **行内菜单（⋯）**：试运行、复制、导出、归档。
- **导入**：选择 `.md` 文件，解析后显示预览和校验结果，确认后创建为草稿。导入的 Agent 默认是草稿状态，必须用户检查后手动发布，因为导入内容可能来自他人。

## 4. Agent 详情与编辑器

### 4.1 布局

```
┌───────────────────────────────────────────────────────────────────┐
│ ← Agents   ● 前端审查员  v3 已发布 · 有未发布修改                    │
│                               [试运行] [保存草稿] [发布 v4] [⋯]     │
├──────────────┬────────────────────────────────────────────────────┤
│ 基本信息      │  模型                                              │
│ 指令      ●  │                                                    │
│ 模型          │  模型来源   ◉ 固定  ○ 跟随会话                       │
│ 能力      ⚠1 │  主模型     [DeepSeek · deepseek-chat        ▾]     │
│ 权限          │             ✓ 支持工具调用 · 上下文 128K · 已验证      │
│ 限额          │  备用模型   [+ 添加]                                 │
│ 上下文        │  辅助模型   [Ollama · qwen2.5:7b             ▾]     │
│ 记忆  即将推出 │             用于压缩上下文、生成标题                   │
│ 高级          │  参数       温度 [0.2]   最大输出 [8192]             │
│ ──────────   │                                                    │
│ 版本历史      │                                                    │
│ 生效配置预览  │                                                    │
└──────────────┴────────────────────────────────────────────────────┘
```

- 左侧为分区导航，显示每个分区的状态：`●` 有未保存修改，`⚠` 有警告（数字为数量），`✕` 有错误。
- 右侧为当前分区的表单。
- 顶部固定操作栏，始终可见。
- 内置 Agent 打开时所有字段只读，顶部只有"复制为新 Agent"和"试运行"。

### 4.2 分区内容

**基本信息**
- 名称、描述：中英文两个输入框并列（见第 13 节）。
- 图标（从图标库选择）、颜色（从设计令牌中的分类色选择，不允许任意色值，保证深浅色模式下都清晰）。
- 标签。

**指令**
- Markdown 编辑器（Monaco），支持全屏编辑。
- 实时显示估算 token 数，以及占当前模型上下文的比例；超过建议值时给出提示。
- 右侧可展开"基础系统提示词"的只读预览，让用户知道自己的指令会接在什么后面。

**模型**
- 固定模型或跟随会话。
- 主模型、备用模型（可排序）、辅助模型。
- 每个模型旁显示能力：是否支持工具调用、上下文大小、最近验证时间；未验证时提供"测试"按钮。
- 选择不支持工具调用的模型时，明确提示该 Agent 将无法使用任何工具。

**能力**
- 三个子标签：工具、Skills、MCP。
- **工具**：按类别分组（读取、写入、执行、网络），每个工具一个开关，类别旁显示风险等级。可以整组开关。
- **Skills**：列表显示已安装的 Skill，可选"全部启用"或逐个勾选；每个 Skill 可以设为"始终加载"，旁边显示其 token 数，提醒占用上下文。
- **MCP**：列出已配置的 MCP 服务及其工具，可以按服务或按工具启用；未连接的服务显示警告。

**权限**
- 选择预设：只读、询问、自动。
- 下方是规则表（来自预设的规则标注"预设"，不可编辑但可以被更严格的自定义规则覆盖）。
- 每条规则用自然语言展示，例如"执行命令 `npm test` → 允许"，也可以切换为结构化编辑。
- 底部固定显示"系统强制规则"（危险命令、工作区外路径、敏感文件），说明这些无法放宽。

**限额**
- 每轮最大步数、最长时间、token 上限、费用上限、连续工具错误上限。
- 每项显示默认值，修改后显示"已修改"并可一键恢复默认。

**上下文**
- 是否读取 `AGENTS.md`、是否自动压缩、预留输出 token。

**记忆**
- 第一版显示为"即将推出"，字段不可编辑，只展示说明。

**高级**
- 输入 / 输出 schema（JSON 编辑器，带校验）。
- 委派设置（多 Agent，未启用时折叠并标注"即将推出"）。

### 4.3 生效配置预览

单独一页，回答"这个 Agent 实际运行时会是什么样"：

- 合并后的完整系统提示词（基础提示词 + Agent 指令 + 示例项目说明位置），可复制。
- 最终可用的工具清单（考虑了 Agent 配置、MCP 连接状态、模型能力）。
- Skills 索引的实际内容和 token 数。
- 生效的权限规则，按判定顺序排列。
- 上下文预算分配（以条形图展示各部分占比）。

这一页对排查"Agent 为什么不用某个工具"非常有用。

### 4.4 校验

- 输入时即时校验，错误显示在字段下方，分区导航上同步显示标记。
- 有错误时可以保存草稿，但不能发布。
- 警告（例如引用的 MCP 服务当前未连接）不阻止发布，但发布确认框中会列出。

### 4.5 未保存修改

- 草稿每隔几秒自动保存到本地（只保存草稿，不会发布）。
- 离开页面时，如果存在未保存的修改，提示保存、放弃或取消。

## 5. 版本与发布

### 5.1 规则

- 发布时创建新版本（版本号 +1），运行引用的始终是具体版本（Runtime 设计 2、3.4 节）。
- 已发布的 Agent 被编辑时，修改进入草稿，不影响已发布版本；会话中选择该 Agent 时仍使用最新的已发布版本。
- 草稿状态的 Agent 不能在会话中选用，只能试运行。

### 5.2 版本历史页

```
┌──────────────────────────────────────────────────────┐
│ 版本历史 · 前端审查员                                  │
├──────────────────────────────────────────────────────┤
│ 草稿    未发布修改：指令、权限                [对比]   │
│ v3 当前 11月2日 10:20  被 4 个会话使用       [对比] ⋯ │
│ v2      11月1日 18:05  被 12 个会话使用      [对比] ⋯ │
│ v1      10月30日 09:40 被 3 个会话使用       [对比] ⋯ │
└──────────────────────────────────────────────────────┘
```

- 任意两个版本可以对比：结构化字段以表格对比，指令以文本 diff 对比。
- 旧版本可以"恢复为草稿"，即以旧版本内容覆盖当前草稿，发布后成为新版本，不会改写历史。
- 显示每个版本被多少个会话使用，点击可查看会话列表。

### 5.3 发布确认

发布前弹出确认框，列出：与上一版本相比的变化摘要、存在的警告、最近一次试运行的结果（如有）。

## 6. 试运行

### 6.1 目的

在不影响真实会话的情况下，验证 Agent 的指令、工具和权限是否按预期工作。

### 6.2 交互

- 在编辑器中点击"试运行"，右侧滑出试运行面板，与编辑器并排显示，方便边改边试。
- 试运行使用**当前草稿**（未发布的修改也生效）。
- 用户选择一个项目；默认以**只读权限**运行，需要写文件或执行命令时，用户可以手动切换为"使用 Agent 自身的权限"。
- 面板中是一个简化的对话界面，同时显示工具调用和审批。
- 修改编辑器中的配置后，面板顶部提示"配置已变化"，可一键用新配置重新开始。

### 6.3 数据

- 试运行在数据库中是普通会话，但标记为 `trial`，不出现在会话列表中。
- 试运行同样创建检查点，写入的改动可以一键回退。
- 试运行记录保留最近若干条，可以在 Agent 详情中查看，也可以手动清除。

## 7. 在会话中使用 Agent

### 7.1 选择 Agent

输入框下方的控件栏：

```
┌──────────────────────────────────────────────────────────────┐
│ 描述你的需求…                                                  │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [◆ 编程助手 ▾]  [DeepSeek ▾]  [询问 ▾]          [发送]         │
└──────────────────────────────────────────────────────────────┘
```

- Agent 选择器列出所有已发布的 Agent，最近使用的排在前面，支持搜索。
- 选择固定模型的 Agent 时，模型选择器显示该模型并禁用，悬停提示"由 Agent 固定"。
- 新建会话默认使用上一次使用的 Agent；在设置中可以指定默认 Agent。

### 7.2 切换 Agent

- 会话中途切换 Agent 时，在同一会话中**创建一个新的运行**，对话中插入一条分隔提示："已切换到 前端审查员 v3"。
- 新运行可以看到之前的对话历史（作为上下文传入），但工具和权限按新 Agent 生效。
- 运行中不能切换，需要先等待完成或停止。

### 7.3 Agent 标识

- 每条 Agent 回复的开头显示小号的 Agent 图标和名称。
- 单 Agent 会话中只在切换时显示，以免干扰；多 Agent 时始终显示（见多 Agent 协作设计）。

## 8. 运行监控

### 8.1 运行状态条

会话顶部常驻一条细的状态条，运行中时显示：

```
◆ 编程助手 v1 · 执行工具 · 第 12/50 步 · 4 分 12 秒 · 38.2K token · ¥0.06   [检查器] [停止]
```

- 状态文字与 Runtime 状态机一一对应：思考中、执行工具、等待审批、已中断等。
- 接近限额（80%）时，该项变为警告色。
- 达到限额时显示"已达上限"，提供"继续"按钮（Runtime 设计 10.3 节）。

### 8.2 检查器

点击"检查器"，右侧面板打开，有四个标签：

| 标签 | 内容 |
|---|---|
| 时间线 | 按轮次 → 步骤 → 工具调用的树状结构，每个节点显示耗时、token、状态；点击定位到对话中的对应位置 |
| 上下文 | 最近一次模型调用实际发送的内容：系统提示词各部分、加载的 Skills、工具定义、历史；附 token 占比条形图；可查看压缩摘要 |
| 用量 | 本运行与本会话的 token、模型调用次数、工具调用次数，按模型分组（按 ADR-0024 不显示费用） |
| 设置 | 本运行使用的 Agent 版本（可跳转）、生效的权限、限额（可临时调整） |

检查器是高级功能，默认不打开，但在排查问题时非常关键。

## 10. 能力管理：Skills 与 MCP

### 10.1 Skills

**列表**：名称、描述、来源（内置 / 已安装 / 项目）、版本或哈希、启用状态、被哪些 Agent 使用、token 数。

**安装**：从本地文件夹或压缩包安装。安装前显示预览：`SKILL.md` 内容、包含的文件、是否包含脚本。包含脚本的 Skill 会特别提示"脚本执行时仍需审批"。

**详情**：完整说明的预览、文件列表、使用记录（哪些运行加载过它）。

**项目 Skill**：在项目设置中开启后，列表中显示该项目的 Skill，并标注来源项目。

### 10.2 MCP 服务

**列表**：名称、类型（本地进程 / 远程地址）、连接状态（已连接、连接中、已断开、错误）、工具数量、被哪些 Agent 使用。

**添加**：
- 本地进程：命令、参数、环境变量（敏感值存入凭据服务，界面只显示"已设置"）、工作目录。
- 远程：地址、认证方式。
- 保存后立即尝试连接，显示结果和获取到的工具列表。

**详情**：
- 工具列表，每个工具可以设置默认权限（允许 / 询问 / 拒绝）和类别（读取 / 写入 / 执行 / 网络），未设置时按最严格处理。
- 连接日志（最近若干条），便于排查启动失败。
- 重新连接、停用、删除。

---

## 11. 归档与删除

- 运行引用 Agent 的具体版本，因此有运行记录的 Agent 不能直接删除，只能**归档**：从列表和选择器中隐藏，历史会话仍能正常显示和解释。
- 归档的 Agent 可以在列表筛选"已归档"中找到并恢复。
- 从未被使用过的 Agent（包括只有试运行记录的）可以彻底删除，删除前确认。
- 内置 Agent 不能归档或删除，但可以在设置中从选择器里隐藏。

---

## 12. 异常与空状态

| 场景 | 表现 |
|---|---|
| 尚无自定义 Agent | 列表下方显示引导："基于编程助手创建你的第一个 Agent"，附一个按钮 |
| 引用的工具或 Skill 已被删除 | Agent 标记为"需要修复"，编辑器中对应项标红并提供"移除"按钮；不能发布，已发布版本在会话中选择时给出警告 |
| MCP 服务未连接 | 黄色警告，不阻止使用；运行时这些工具不可用，模型不会看到它们 |
| 模型不可用（Ollama 未启动、Key 无效） | 选择器中显示不可用状态和原因，并给出"去设置"链接 |
| 模型不支持工具调用 | 选择时明确提示该 Agent 只能纯对话 |
| 导入文件格式错误 | 显示具体的错误位置和原因，不创建草稿 |
| 加载失败 | 显示错误码对应的说明和"重试"按钮 |

## 13. 国际化

- 名称和描述使用 `LocalizedText`：编辑器中中英文输入框并列，至少填写一种语言才能保存。
- 显示时优先当前界面语言，缺失时回退到另一种语言，并在编辑器中提示"未填写英文名称"。
- 指令只有一份，不区分语言。由用户自己决定用中文还是英文写；界面中提示"英文指令在部分模型上效果更稳定"。
- 内置 Agent 的名称、描述由应用的语言资源提供。

## 14. 键盘与无障碍

- 全局快捷键：`Ctrl+1～5` 切换导航入口，`Ctrl+K` 打开命令面板（可搜索 Agent、会话、设置项）。
- 编辑器：`Ctrl+S` 保存草稿，`Ctrl+Enter` 在试运行面板中发送。
- 输入框中 `Ctrl+.` 打开 Agent 选择器。
- 所有可交互元素可通过键盘访问，焦点样式清晰可见。
- 状态不只用颜色表示，同时配合图标和文字（如警告图标 + "未连接"）。
- 状态条和活动中心的变化通过 `aria-live` 通知屏幕阅读器。
