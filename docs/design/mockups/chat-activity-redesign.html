这版改了什么

1去掉竖线，也去掉品牌图形

一条从头贯到尾的灰线，在 22 行的长度上只剩啰嗦。整条竖线和组头那颗环石 C 都删掉，步骤靠图标列 + 行高节奏成组，不再靠画线。

2每个状态一个图标

完成是对勾、执行中是缺口转圈、失败是叉、等待是空圈、取消是横杠。形状本身就说明状态，颜色只做辅助。

3组头只说一句话：现在在干什么

执行中是 正在运行 + 当前命令，每来一条工具事件整体替换一次；结束时变成结果 已执行 22 个步骤；失败时直接写 npm run typecheck 失败。没有构成统计、没有进度分数、没有沙箱标签。

4失败时组头就是那句错误

不写「执行中断 · 1 个步骤失败」这种描述性总结，直接写失败的那条命令加「失败」。往下第一条红行就是它的退出码与报错，扫一眼就知道断在哪。

5一步一行，行高 28px

原来每个步骤是独立消息，彼此还留着 28px 的段落间距，22 步被拉成一篇长文。现在四栏对齐（图标 / 动作 / 对象 / 耗时），行高收到 28px，一行里的信息一个字没少。

6思考压成一行，沙箱挪进详情

「思考」从四颗独立按钮压成一行淡字（思考 · 一句话摘要），顺带把 22 步切成 4 个阶段。沙箱信息原来每条命令右边挂一枚，现在不占行内位置——展开某一步时，在详情里看这一条命令的沙箱与退出码。
