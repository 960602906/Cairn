## 1. 原则

- **对话是主场**：对话保持主列；改动、会话要点和完整计划放在右侧会话栏，按标签查看，不挤进消息流。
- **专业、冷静、克制**：中性灰为主，只有一个强调色；层次靠底色差、发丝线和柔和阴影，不靠粗边框和大色块。
- **看得清 Agent 在做什么**：每一步工具调用、每一处文件改动、每一条命令输出都有清楚的位置。
- **改了能退回**：检查点和撤销入口在每一轮都看得到；危险操作必须醒目确认。
- **状态不只靠颜色**：同时配图标或文字（例如 ✓ 加“退出码 0”）。

## 2. 布局

```
┌───────────────┬──────────────────────────────────────────────┐
│ ● ● ●     ▢   │  项目 / 会话标题        [2 个文件 +11 −1] ⟲ ⋯ │
│ ✎ 新对话  ⌃N  │ ┌──────────────────────────────────────────┐ │
│ ⌕ 搜索    ⌃K  │ │                                          │ │
│ ∿ 活动     1  │ │        对话单列，最大宽度 700px            │ │
│ ☺ Agents      │ │                                          │ │
│               │ │                                          │ │
│ 项目 A        │ │                                          │ │
│  ◌ 会话一     │ │   ┌──────────────────────────────────┐   │ │
│  ● 会话二     │ │   │ 运行状态条                        │   │ │
│ 项目 B        │ │   │ 输入框                            │   │ │
│  …            │ │   │ 📎 询问      供应商·模型 ◔  ■      │   │ │
│ ┌───────────┐ │ │   └──────────────────────────────────┘   │ │
│ │模型供应商 │ │ └──────────────────────────────────────────┘ │
│ └───────────┘ │                  纸面（--paper）              │
└───────────────┴──────────────────────────────────────────────┘
   侧栏 252px，铺在窗口底色（--chrome）上
```

- 窗口底色 `--chrome`；侧栏宽 252px，没有自己的背景和边框。
- 纸面 `--paper` 从窗口顶部铺到底部，与侧栏共用窗口边缘，不再做悬浮卡片、外阴影或顶部留白；侧栏与纸面之间用 0.5px 发丝线分隔。
- 纸面顶栏与系统标题栏同高 48px：左边是会话标题，右边是项目名与会话信息栏开关；Windows / Linux 的系统按钮直接叠在这条白色顶栏上。
- 对话右侧是 304px 的会话信息栏，包含“改动 / 会话要点 / 计划”三个标签；宽窗口默认展开，可随时收起；窄窗口改为浮层，不挤压主对话宽度。
- 对话列最大宽度 700px，左右至少 28px 内边距；底部留出输入框的高度。
- 输入框悬浮在纸面底部，最大宽度 720px。
- 侧栏内容从上到下：窗口按钮与收起侧栏、Cairn 品牌行、新对话、搜索、活动（待处理数角标）、Agents，可折叠的项目分组会话列表，底部是“设置”。
- 窗口宽度不足 880px 时侧栏收起。

## 4. 字体与字号

- 界面字体：`-apple-system, "PingFang SC", "Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif`，不内置界面字体。
- 等宽字体：`"JetBrains Mono"`（随应用打包），回退 `"Cascadia Code", Consolas, Menlo, monospace`。所有代码、路径、命令关闭连字（`font-variant-ligatures: none`），`=>` 不能显示成箭头。
- 数字列和计数用等宽数字（`font-variant-numeric: tabular-nums`）。

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 设置页标题 | 22px | 600 |
| 对话框标题 | 17px | 600 |
| 回复中的小标题 | 16px | 600 |
| 对话正文（用户和助手） | 15px / 1.78 | 400 |
| 侧栏、按钮、工具步骤 | 13.5px | 400，选中 500 |
| 代码、diff | 13px / 22px | 400 |
| 终端输出 | 12.5px / 21px | 400 |
| 说明、时间、计数 | 11.5–12.5px | 400 |

## 5. 形状、间距与动效

- 圆角：小按钮和侧栏项 7–8px，卡片 12px，审批卡片 14px，对话框 18px，输入框 20px，用户消息气泡 20px，应用图标 22.5%。
- 描边：一律用 0.5px 的 `--hair` / `--hair2`（用 `box-shadow: 0 0 0 .5px` 实现），不用 1px 实线框。
- 阴影：只有浮起的东西才有阴影；普通内容块只用描边。
- 间距：以 4px 为单位；对话流中块与块之间 14px，轮与轮之间 28px。
- 动效：悬停和切换 150ms，曲线 `cubic-bezier(.2,.8,.2,1)`；运行中用小转圈和流光文字；尊重 `prefers-reduced-motion`，关闭所有循环动画。

## 6. 对话页组件

- **用户消息**：右对齐气泡，底色 `--sunk2`，最大宽度 78%；附带的文件以小卡片显示在气泡上方（语言图标 + 路径）。
- **思考过程**：一行灰字“思考了 6 秒”，可展开。
- **工具时间线**：每一步一行，左侧是节点（完成为绿色 ✓，进行中为转圈），节点之间有 1px 竖线；文字是“动作 + 对象”（例如“读取 `src/sum.mjs`”），右侧灰字是耗时或结果摘要。正在进行的步骤用流光文字。
- **助手正文**：完整渲染 Markdown（标题、列表、表格、行内代码、代码块）。
- **审批卡片**：浮起的卡片（`--sh-2`）。标题“要运行这条命令吗？”，下面是命令、触发审批的原因，再下面是编号选项：
  1. 运行一次（Enter）
  2. 运行，并且以后同类命令不再询问（写明作用范围：仅此项目）
  3. 不运行，告诉 Agent 换个做法（Esc）
  数字键 1–3 直接选择。
- **检查点分隔线**：每轮结束处一条细线，中间写“第 N 轮前已保存检查点 · 时间”。
- **轮次操作**：复制、撤销本轮；右侧灰字显示模型名和 token 数。
- **输入框**：上方是运行状态条（转圈 + “正在运行 · 已用时间” + “按 Esc 停止”）；下方左边是附件、权限模式，右边是“供应商 · 模型”选择、上下文占用圆环（悬停显示百分比）、发送或停止按钮（近黑圆形）。
- **危险操作确认框**：模糊遮罩 + 对话框；左上角红色图标，标题写清动作（“撤销第 3 轮的改动？”），正文说明后果，列出受影响的文件并标出每个文件会怎样（恢复原内容 / 删除）；两个等宽按钮，取消在左，红色主按钮在右，按钮文字写明数量（“撤销 2 个文件”）。

## 7. 代码区

### 7.1 代码卡片

- 标题栏高 38px，底色 `--code-head`：语言图标（16px 小方块）、路径（目录用 `--muted`，文件名用 `--fg` 加粗）、“新文件”标记、增删行数；右侧是“换行”和“复制”按钮，复制后显示“已复制”1.6 秒。
- 正文：行号列宽 46px，右对齐，`--gutter` 色，不可选中，复制时不带行号。
- Agent 要你注意的行：底色 `--line-hl`，左侧 2px 强调色竖线，行号变为强调色。
- 语法高亮按令牌着色：关键字、函数、字符串、数字、注释（斜体）、标点、类型、属性名。

### 7.2 diff 卡片

- 标题栏与代码卡片相同，增删行数后面跟 5 个小方块表示增删比例；右侧是“合并 / 分栏”切换和“撤销此文件”。
- hunk 标题行：`@@ -1,6 +1,6 @@` 加所在函数名，底色 `--hunk-bg`。
- 每行：旧行号、新行号、`+`/`−` 标记、内容。新增行和删除行整行着色，行号槽颜色更深；行内真正改动的词用 `--add-word` / `--del-word` 再加深一层。
- 未改动的连续代码折叠成一行“展开下方 N 行未改动的代码”。
- 分栏视图：左旧右新，中间 0.5px 分隔线；对侧没有对应行时用斜线底纹占位。窗口宽度不足时自动退回合并视图。

### 7.3 终端卡片

- 无论浅色还是深色主题，都使用深色终端令牌（`--term-*`）。
- 标题栏：`$ 命令`、退出码徽标（0 为绿色 ✓，非 0 为红色 ✕）、耗时、复制。
- 输出区最高 220px，超出后内部滚动；底部一行汇总（例如测试的通过、失败、跳过数量，以及 Shell 和工作目录）。

### 7.4 本轮变更

每轮结束、有文件改动时出现：标题“本轮变更”和总增删数，下面每个文件一行（语言图标、路径、新文件标记、增删数、比例方块），点击打开对应的 diff。

## 8. 设置页

- 与对话页相同的窗口结构：左侧分类导航（顶部 Cairn 品牌行与“返回对话 Esc”），右侧纸面，内容居中，最大宽度 840px；表单标签列 148px。
- 分类：通用与外观；模型供应商；MCP 服务、技能；权限与审批。
- **模型供应商**：列表每行显示图标、名称、来源标记（官方 / 第三方中转）、接口格式、模型数、默认标记和连接状态。编辑区依次是：接口格式（Anthropic / OpenAI / Gemini 三选一的卡片）、来源（选“官方”自动填写地址和兼容参数）、名称、Base URL、API Key（显示末 4 位和“已保存到系统钥匙串”）、测试连接结果、模型列表（开关、默认、上下文长度、能力）、高级选项（折叠）。
- **MCP 服务**：每个服务显示名称、类型（本机进程 / 远程 HTTP）、启动命令或地址、连接状态、开关和工具列表；失败时在行内说明原因并提供“查看日志”。下方显示可复制的 `mcp.json`，格式兼容 Claude Desktop 和 Cursor，支持导入。
- **技能**：两列卡片，显示名称、说明、作用范围（全局或某个项目）、路径和开关；支持拖入文件夹或 .zip 安装，安装前展示其中的脚本让用户确认。
- **权限与审批**：只读 / 询问 / 自动三种模式卡片；规则列表按匹配顺序排列，每条显示效果（允许 / 询问 / 拒绝）、规则和来源；底部说明哪些操作无论规则如何都会再次询问。
- **通用与外观**：主题、界面语言、默认 Shell、全局指令。

## 9. 图标与品牌

- 产品名 Cairn（石标），见 [ADR-0025](../adr/0025-product-name-cairn.md)。
- 应用图标：三块叠起的石头，黑白灰。默认浅灰底板加黑色图形；深色版黑底白图形。24px 及以下使用放大图形的小尺寸版本。
- 源文件和各尺寸导出放在 `apps/desktop/build/icons/`。
- 界面品牌行常驻侧栏顶部：22px 叠石图形加 `Cairn` 字标；新对话欢迎页使用 64px 图形，空会话与无 preload 回退页也显示品牌图形。
