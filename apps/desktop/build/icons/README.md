# 应用图标

Cairn（石标）的应用图标，规范见 [视觉规范](../../../../docs/design/visual-style.md) 第 9 节。

| 文件 | 用途 |
|---|---|
| `icon.ico` / `icon.icns` / `icon.png` | 默认（浅色底板）：Windows、macOS、Linux，PNG 为 1024px |
| `icon-dark.*` | 深色底板版本 |
| `glyph.svg` | 只有图形、没有底板，用于加载页、关于页 |
| `icon-light.svg` / `icon-dark.svg` | 带底板的矢量源文件 |
| `icon-*-small.svg` | 24px 及以下使用，图形放大到撑满底板 |

`.ico` 包含 16、20、24、32、40、48、64、128、256 九个尺寸。
